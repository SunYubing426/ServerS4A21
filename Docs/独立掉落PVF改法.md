# 独立掉落怎么改（给改 PVF 的人）

只改 `etc/independent_drop.etc`。改完重新打包 `Script.pvf`，更新游戏服上的 PVF，**重启游戏服**。只改客户端目录不够。

这张表是「某个怪物死了额外掉什么」，和怪物模板自己的 `[item]`、金币、世界掉落不是同一条。

## 先抄一行再改

不要凭空写。在文件里找一个**已经会掉**的同类行，复制整行（如果有 `[list]` 就连块一起抄），只改怪物 CODE 和物品。

新怪必须**新增一行**。只改已有行，是在换那个旧怪的掉落，不会让新怪开始掉。

## 一行必须是 17 个整数

```text
类型  怪物CODE  物品ID
难度0概率 难度1 难度2 难度3 难度4
数量0 数量1 数量2 数量3 数量4
等级下限 等级上限 指定难度 list标志
```

常用写法（固定掉一件，各难度都 100%）：

```text
0 怪物CODE 物品ID 1000000 1000000 1000000 1000000 1000000 1 1 1 1 1 0 0 -1 0
```

随机几件之一：

```text
0 怪物CODE 0 1000000 1000000 1000000 1000000 1000000 1 1 1 1 1 0 0 -1 1
[list]
物品A 100
物品B 100
[/list]
```

`[list]` 里是 `物品ID 权重`，权重越大越容易抽中。两个都写 `100` 就是各 50%。

整段必须包在：

```text
[independent drop]
...所有行...
[/independent drop]
```

新行写在 `[/independent drop]` **前面**。

## 字段怎么填

| 位置 | 怎么填 |
| --- | --- |
| 类型 | 固定写 `0`。写 `1` 当前服不吃，等于没配。 |
| 怪物 CODE | 怪物脚本编号，不是中文名、不是地图 ID。 |
| 物品 ID | 固定掉落写物品编号。走 `[list]` 时这里写 `0`。 |
| 五个概率 | `1000000` = 100%。写 `100` 是十万分之一，看起来像「完全不掉」。 |
| 五个数量 | 当前服用**第一个**数量。要掉 1 个就把五个都写成 `1`。 |
| 等级上下限 | `0 0` 表示不限制本副本等级。要限制就写例如 `1 19`。 |
| 指定难度 | `-1` = 所有难度。只想普通难度再改成 `0`。 |
| list 标志 | `0` = 用上面的物品 ID；`1` = 必须跟 `[list]`；`2` 是异界外部池，不要随便用。 |

## 坑（按出现频率）

1. **少写或多写一个数字。** 必须刚好 17 个。少一个会把下一行吃进去，后面整段都乱。
2. **第一位写成 `1`。** 当前服忽略这种行。要必掉：类型 `0`，概率 `1000000`。
3. **概率当百分比写。** `100` 不是 100%。100% 是 `1000000`。
4. **新怪没加新行。** 改旧行只会影响旧怪。
5. **list 标志写了 `1`，却没有 `[list]...[/list]`。** 这行不会掉。
6. **走 `[list]` 时第三列还写了物品 ID。** 第三列应是 `0`，真正的候选在 list 里。
7. **物品没在 `equipment.lst` / `stackable.lst` 登记。** 表能写上，进游戏可能出不来或捡不起来。先确认物品能正常出现在游戏里，再拿它做独立掉落。
8. **编辑器里的箭头 `→`。** 界面显示 `0 → 60005 → 3015` 没关系，存进 PVF 时用空格分开的纯数字。不要把箭头、中文名、`#` 注释粘进数字中间。
9. **只更了客户端 PVF。** 独立掉落是服务端读的。必须更新并重启游戏服。
10. **用错怪物 CODE。** 打死 A 怪却配了 B 的 CODE，A 不会掉。

## 改完怎么验

1. 打包后的 `Script.pvf` 里再打开 `etc/independent_drop.etc`，确认新行还在，仍是 17 个数字。
2. 重启游戏服。
3. 进对应副本打**那只怪**（看 CODE 对不对）。
4. 概率先用 `1000000` 测，确认能掉再改成正式概率。
5. 如果「新怪不掉，原来会掉的怪也不掉了」：多半是某一行数字个数不对，或 `[list]` 没闭合。把新行删掉，先恢复成只改旧行能掉的状态，再按上面抄一行重加。

## 最小检查清单

- [ ] 类型是 `0`
- [ ] 怪物 CODE 对
- [ ] 刚好 17 个整数
- [ ] 概率按百万分率（100% = `1000000`）
- [ ] 新怪是新增行，写在 `[independent drop]` 里面
- [ ] `list` 标志 `1` 时有成对的 `[list]` / `[/list]`
- [ ] 物品已在 lst 里、游戏里能正常出现
- [ ] 服务端 PVF 已更新并重启
